# wdipt

**拾间 · Where Did I Put Them** — 用平面图搭建住宅、自动生成 3D 模型，并记住每件物品放在哪里。

一条命令启动完整应用（Fastify 后端 + Vue / Three.js 前端静态资源）。需要 Node.js >= 22。

## 使用

```bash
# 不安装，直接运行
npx wdipt

# 或全局安装
npm install -g wdipt
wdipt
```

启动后打开 <http://127.0.0.1:8787>。默认监听 `0.0.0.0`（局域网可访问）；只在本机使用可加 `--host 127.0.0.1`。

```bash
wdipt --port 9000
wdipt --host 127.0.0.1
wdipt --data-dir ./my-home-data
wdipt --help
wdipt --version
```

| 参数 | 环境变量 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--port` | `PORT` | `8787` | HTTP 端口 |
| `--host` | `HOST` | `0.0.0.0` | 监听地址 |
| `--data-dir` | `DATA_DIR` | `~/.wdipt` | SQLite 数据库目录 |
| `--web-dist` | `WEB_DIST` | 包内 `dist/web` | 自定义前端目录 |

首次运行会在数据目录生成两栋示例住宅：「梧桐宅」包含 2 层和楼梯，「河畔工作室」是一层带弧形采光的工作室。数据保存在 `wdipt.db`（SQLite 3.53.4，WAL 模式）；WebSocket 实时同步多个窗口。

## 功能

- 多住宅：右上角菜单新建、切换自己的房子
- 多楼层：顶部楼层条添加 / 复制 / 删除 / 切换楼层
- 楼梯：连接上下层，上层地板自动开洞
- 回收站：删除住宅先进回收站；永久删除需要输入 4 位随机验证码
- 平面模式：矩形 / 椭圆地面的融合与挖除、墙体、门窗、家具
- 立体模式：根据每层平面自动生成墙体、门窗洞口、地板、楼梯与程序化家具，可切换整栋 / 当前层
- 每件家具拥有独立物品数组，可记录名称、数量、备注
- `Ctrl / ⌘ + K` 全局查找物品，跨房子和楼层自动定位并高亮
- WebSocket 自动保存与多窗口协同
